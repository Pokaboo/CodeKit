# CodeKit 界面重设计提案

> 日期：2026-08-02
> 对象：当前 antd 后台界面（主色 #1677ff、深色 Sider #001529、浅灰内容区）
> 目标：全面提升美观度与用户体验，输出可直接落地的完整设计规格

---

## 一、现状问题诊断

### 1.1 布局失衡
- **宽屏利用率低**：内容区 `max-width: 1200px` 居中，≥1440px 屏幕上两侧余白过大；三栏工作台（输入/输出均分 + 配置 240px）对窄内容工具（如 MD5、ASCII 编解码）输出栏明显空荡
- **纵向关系弱**：顶栏 48px 与 Sider Logo 区同高但无视觉呼应；Sider 底部版本号与菜单区衔接生硬
- **内容页标题区**（`18px/500`）与正文区分度不足，页面缺少"层级入口"感

### 1.2 间距无节奏
- 全局 `padding 16px` 一刀切；卡片内边距 14px 偏紧
- 卡片内标题与正文间距 4px、配置项行距 8px，整体密度偏高、呼吸感不足
- 区块间距未遵循 8px 基准网格（8/16/24/32/48 梯度），各间距数值散落

### 1.3 色彩层级弱
- 主色 `#1677ff` 同时承担按钮、菜单选中、链接、图标、标签全部角色，缺少"辅助色 / 强调色"分工 → 界面"全蓝一片"缺乏焦点
- 中性色使用散落的 `rgba(0,0,0,.45/.55/.75/.85)`，未收敛为色阶 token，深浅层级不统一
- 深色输出块 `#1e1e1e`（VS Code 风格）与浅色环境割裂，未与 Sider 深色形成呼应
- 成功绿 tag、提示卡片的 9 种 tone 颜色过于抢眼，与整体灰蓝色系不协调

### 1.4 字体层级混乱
- 全局 `fontSize 13` 偏小；页面标题 `18px/500` 与正文区分不足；无 Display 级标题
- 字重仅用 400/500，层级对比靠字号单维；行高统一 1.6，多行文本略挤
- 中文字体栈未指定（缺 PingFang SC / HarmonyOS Sans），Windows/macOS 渲染观感不一
- 代码字体 JetBrains Mono 未区分大小场景（输入框/输出块均 12px）

### 1.5 组件同质化
- 所有卡片同权（白底 + 1px 细边框 + 6px 圆角），无"主卡片/次卡片"视觉权重差异
- 按钮 hover 仅透明度变化，无位移/阴影反馈；点击反馈弱
- 表格未定制（默认样式），与整体气质脱节
- 面包屑、tag、提示条等细组件尺寸与间距不统一

### 1.6 响应式粗糙
- 工作台在 `xl(1200px)` 断点直接三栏→单列跳变，800-1199px 中间态要么三栏过挤、要么浪费空间
- 内容区 padding 不随视口缩放（16px 固定）

## 二、风格方向对比

| 维度 | A · 简约现代（推荐） | B · 深色科技（备选） | C · 杂志风（不推荐） |
|------|---------------------|---------------------|---------------------|
| 气质 | 冷静工具感：Vercel / Linear / Notion 同类 | 沉浸式：VSCode / 极客感 / 数据大屏 | 编辑感：独立博客 / 期刊 |
| 基底 | 浅灰白 `#f8fafc` + 白卡 | 深蓝黑 `#0b1220` + 半透明卡 | 暖白纸感 `#faf7f2` |
| 主色 | 沉稳蓝 `#2563eb` | 亮蓝 `#3b82f6`（可配蓝紫渐变） | 琥珀 `#b45309` |
| 强调 | 紫 `#8b5cf6` 克制点缀 | 紫 `#a855f7` 高光 | 珊瑚 `#e07a5f` |
| 布局 | 12 列栅格、对称、密度适中 | 同左但块面化 | 非对称、展示性大标题 |
| 适用场景 | **高频操作型开发工具**、SaaS 后台 | 开发者工具深色偏好、演示/直播 | 内容型产品、品牌页 |
| 优点 | 普适、易维护、可访问性好、长时阅读舒适 | 辨识度高、聚焦感强、与代码块融合、夜用友好 | 有气质、差异化强 |
| 缺点 | 个性相对内敛，需要细节质感支撑 | 长文本易疲劳、对比度需谨慎、部分用户不习惯 | 信息密度低、与高频操作冲突、开发成本高 |

**推荐 A**：CodeKit 是高频、务实的转换工具，用户核心诉求是"快速、准确、可读"，简约现代风在信息密度与舒适度之间最平衡；且 A 的 token 体系可在后续零成本切换深色模式（复用 B 的部分 token）。

## 三、推荐方案 A 完整规格

### 3.1 设计原则
1. **克制的色彩**：色彩只用于表达状态与引导，不用于装饰
2. **清晰的层级**：每屏最多 3 个视觉层级（标题 / 内容 / 辅助）
3. **呼吸感**：留白是设计的一部分，间距遵循 8px 基准网格
4. **工具感**：信息密度适中，一眼定位输入→配置→输出

### 3.2 布局结构（12 列栅格 + 区块划分）

```
┌─────────┬──────────────────────────────────────────────┐
│         │ 顶栏 48px：折叠钮 · 面包屑 · 状态徽标 · GitHub  │
│ Sider   ├──────────────────────────────────────────────┤
│ 220px   │ 内容区 padding 24px（≥1440 时 32px）            │
│ 深色     │  ┌────────────────────────────────────────┐  │
│ slate-  │  │ 页标题区：20px 标题 + 描述 + 状态 Tag     │  │
│ 900     │  ├──────────┬──────────┬──────────────────┤  │
│ 图标    │  │ 输入面板   │ 配置面板   │ 输出面板          │  │
│ 菜单    │  │ (1fr)     │ 280px    │ (1fr)            │  │
│         │  └──────────┴──────────┴──────────────────┘  │
│         │  卡片间距 20px · 卡片内边距 20px                │
└─────────┴──────────────────────────────────────────────┘
```

- **栅格**：内容区 12 列栅格；三栏工作台 `minmax(0,1fr) 280px minmax(0,1fr)`（≤1400px 时配置栏 240px）
- **留白节奏**（8px 基准）：页面边距 24/32、区块间距 24、卡片内边距 20、卡片内元素间距 16、行内间距 12、紧凑组件间距 8
- **纵向节奏**：页标题下 20px 接工作台；页脚信息行与主体间距 16px
- **权重区分**：工具页标题区为"主视觉锚点"（20px 标题 + 描述），工作台为操作主体，底部表格为次级信息

### 3.3 配色方案（token 化）

| 角色 | Token | 色值 | 用途与比例 |
|------|-------|------|-----------|
| 主色 | `--color-primary` | `#2563eb` | 主按钮、菜单选中、链接、焦点环（约 25% 视觉占比） |
| 主色-hover | `--color-primary-hover` | `#1d4ed8` | 主按钮/链接 hover |
| 主色-浅底 | `--color-primary-soft` | `#eff6ff` | 选中卡片底、标签底、提示条底 |
| 辅助色 | `--color-secondary` | `#64748b` | 次要按钮图标、次级文本（与中性色合并使用） |
| 强调色 | `--color-accent` | `#8b5cf6` | 仅 3 处：Logo 徽标、新功能徽标、执行按钮 hover 高光（约 5%） |
| 成功 | `--color-success` | `#10b981` | 状态 tag、成功提示 |
| 警告 | `--color-warning` | `#f59e0b` | 警示提示条 |
| 错误 | `--color-danger` | `#ef4444` | 错误提示、清空按钮 |
| 中性-背景 | `--color-bg` | `#f8fafc` | 内容区底 |
| 中性-表面 | `--color-surface` | `#ffffff` | 卡片、顶栏 |
| 中性-边框 | `--color-border` | `#e2e8f0` | 卡片、表格线 |
| 中性-深色 | `--color-nav` | `#0f172a` | Sider 底（比纯黑 #001529 更柔和） |
| 文本-主 | `--color-text-1` | `#0f172a` | 标题、正文 |
| 文本-次 | `--color-text-2` | `#475569` | 描述、次级信息 |
| 文本-弱 | `--color-text-3` | `#94a3b8` | 占位、辅助说明 |

**使用比例（60-25-15）**：约 60% 中性白灰（背景/卡片/文本）、25% 主蓝（交互元素）、15% 语义色与强调色（状态表达）。**禁止大面积铺色**，除 Sider 深色外，主色只出现在交互与选中态。

### 3.4 字体与字号层级

- **中文字体栈**：`"PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif`（回退到 Outfit 现有栈）
- **英文数字**：`Inter`（或保留 Outfit）；**代码**：`JetBrains Mono` 不变
- **字号层级**（8px 步进系）：

| 层级 | 字号/字重 | 行高 | 场景 |
|------|-----------|------|------|
| Display | 24px / 600 | 1.3 | 页标题（当前 18px → 提升） |
| Section | 15px / 600 | 1.5 | 卡片标题（面板标题） |
| Body | 14px / 400 | 1.7 | 正文、按钮、菜单（当前 13px → 提升） |
| Caption | 12px / 400 | 1.6 | 描述、徽标、表格单元格 |
| Code | 13px / 400 | 1.7 | 输入/输出代码块（当前 12px → 提升） |

**层级规则**：标题用字重 600 而非加大字号；正文 14px 保证中文可读性；代码块 13px 平衡密度与可读性。

### 3.5 组件规范

**卡片**
- 基础：白底、`1px solid #e2e8f0`、圆角 `12px`、内边距 `20px`
- 主卡片（输入/输出）：可选顶部 3px 主色指示条，hover 提升为 `0 4px 16px rgba(15,23,42,.06)` 轻阴影
- 次卡片（配置/提示）：无指示条，hover 仅边框加深
- 卡片间距统一 20px

**按钮**
- Primary：主色底白字、圆角 8px、高度 36px；hover 加深 + `translateY(-1px)`；active `translateY(0)` + 轻微缩小
- Default：白底、1px 边框；hover 边框/文字转主色
- Text：无底；hover 浅灰底
- 图标按钮与文字按钮同一高度体系

**导航（Sider）**
- 底色 `#0f172a`（slate-900）；菜单项圆角 8px、高度 40px
- 选中态：主色底 + 白字 + 左侧 3px 白色指示条（强化当前位置感）
- hover：`rgba(255,255,255,.06)` 底
- Logo 区：主色渐变徽标（`#2563eb → #8b5cf6`）+ 48px 高，与顶栏呼应

**表格**
- 容器圆角 12px、`1px` 边框；表头 `#f8fafc`、12px/600 灰字
- 行高 44px、hover `#f8fafc`；无纵向分隔线（极简）

**输出代码块**
- 底色统一为 `#0f172a`（与 Sider 呼应，替代孤立 `#1e1e1e`）
- 顶部 tab 栏 `#1e293b`，文件名 12px；内容 13px / 行高 1.7

**其他**
- 面包屑：当前项主色、上级 `#64748b`；分隔符 `#cbd5e1`
- Tag：浅底深字（`--color-primary-soft` 底 + 主色字），不再用高饱和底
- 提示条（InfoCard）：统一主色浅底系，tone 收敛为 4 种（info/success/warning/danger）而非 9 种杂色

### 3.6 响应式策略

| 断点 | Sider | 工作台 | 内容边距 |
|------|-------|--------|----------|
| ≥1440px | 展开 220px | 三栏 `1fr 280px 1fr` | 32px |
| 1200–1439px | 展开 220px | 三栏 `1fr 240px 1fr` | 24px |
| 992–1199px | 折叠 64px 图标栏 | 输入/输出并排，配置栏移至下方左侧行 | 20px |
| 768–991px | 折叠 64px | 输入/输出并排（配置合并为浮层或折叠区） | 16px |
| <768px | Drawer 抽屉 | 单列堆叠：输入 → 配置 → 输出 | 12px |

- 配置面板在中间态下"下沉"：改为工作台第二行（左侧 1/3）或可折叠抽屉，避免挤压
- 输出区在窄屏可置于底部固定高度（滚动），保证输入区始终可编辑

## 五、待确认决策点

1. **风格方向**：确认采用 A 简约现代？（B 深色科技可作为后续"深色模式"开关增量实现，antd `darkAlgorithm` 支持）
2. **主色**：从 `#1677ff` 调整为更沉稳的 `#2563eb`，还是保留原色？（两者均可一键切换）
3. **页面标题层级**：是否接受 18px → 24px 的 Display 级提升（更明显的"入口感"）？
4. **代码块深色**：输出区从 `#1e1e1e` 统一为与 Sider 呼应的 `#0f172a`，还是维持 VS Code 经典观感？

*本提案为设计规格，确认后按实施清单落地，不改动任何业务逻辑。*
