## Bug 修复：Sider 菜单无法滚动

- 根因：antd Sider 内部有中间层 `.ant-layout-sider-children`（默认 block），Sider 上的 flex 布局实际作用在该层，导致菜单容器的 flex:1/overflow:auto 失效 → 菜单被外层裁剪且无法滚动（经典 flex 子项 min-height 问题）。
- 修复：Sider 加 className="ck-sider"，index.css 覆盖 `.ck-sider .ant-layout-sider-children { display:flex; flex-direction:column; height:100% }` + `.ck-sider-menu { flex:1; min-height:0; overflow-y:auto }`，logo 与版本号固定、菜单区独立滚动。
